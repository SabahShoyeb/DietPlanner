# Diet Planner

## Overview

Diet Planner is a beginner-friendly Java GUI application that allows users to enter personal information and generate a meal plan based on their preferences.

The application also maintains a history of previously generated meal plans for reference.

## Features

- Java-based graphical user interface
- Collects user information such as:
  - Name
  - Age
  - Weight
  - Height
  - Gender
  - Diet preference
  - Number of meals per day
- Generates meal plans based on user input
- Supports different meal categories
- Stores previously generated meal plans in a history file

## Meal Categories

The project includes different meal types, including:

- Vegetarian
- Non-Vegetarian
- Vegan

## Technologies Used

- Java
- Java GUI
- File Handling
- Object-Oriented Programming

## Project Structure

The project includes classes for:

- `DietPlannerFrame` — GUI interface
- `Main` — application entry point
- `Meal` — meal-related functionality
- `MealType` — meal type representation
- `MealFileManager` — meal history file management
- `VegetarianMeal` — vegetarian meal implementation
- `NonVegMeal` — non-vegetarian meal implementation
- `VeganMeal` — vegan meal implementation

## Learning Objective

The project was developed to gain practical experience in Java GUI development, Object-Oriented Programming, file handling, and application design.
